# carte blanche

Что получилось, когда Claude сказали «делай тут что хочешь». Повторили одиннадцать раз.

**Витрина: https://reuniko.github.io/carte-blanche/**

Всё работает прямо в браузере: каждая страница — один HTML-файл без зависимостей и без сборки.

| | Что это |
|---|---|
| [Лучи](https://reuniko.github.io/carte-blanche/rays.html) | Головоломка с зеркалами: зажгите все кристаллы одним лучом маяка. Уровни генерируются бесконечно и всегда решаемы. |
| [Часы словами](https://reuniko.github.io/carte-blanche/clock.html) | Время по-русски: «без четверти шесть», «двадцать одна минута четвёртого». |
| [Ночной город](https://reuniko.github.io/carte-blanche/city.html) | Бесконечная панорама под дождём: параллакс, мокрый асфальт, поезд. Окна включаются кликом. |
| [Ткань](https://reuniko.github.io/carte-blanche/cloth.html) | Полотно на физике Верле: тяните, режьте, включайте ветер. |
| [Черепашка](https://reuniko.github.io/carte-blanche/turtle.html) | Маленький язык программирования на русском в духе Logo: циклы, условия, рекурсия. |
| [Узоры](https://reuniko.github.io/carte-blanche/patterns.html) | Реакция-диффузия Грея — Скотта на WebGL2: кораллы, лабиринты, делящиеся клетки. |
| [Смотритель](https://reuniko.github.io/carte-blanche/beacon.html) | Игра: ночью ведите лучом маяка лодки мимо рифов. Со звуком, лучше в наушниках. |
| [Стая](https://reuniko.github.io/carte-blanche/flock.html) | Симуляция стаи по правилам Рейнольдса: приманки, хищники, ползунки поведения. |
| [Сетка звуков](https://reuniko.github.io/carte-blanche/tenori.html) | Секвенсор в духе Tenori-on на Web Audio. |
| [Остров с маяком](https://reuniko.github.io/carte-blanche/island.png) | Низкополигональная сцена, собранная кодом в Blender. Есть [видео облёта](https://reuniko.github.io/carte-blanche/island_0001-0240.mp4) и сам [`island.blend`](island.blend). |

Локально: склонируйте репозиторий и откройте `index.html` двойным кликом, сервер не нужен.
